# 未収録信号とレスポンシブ表示

## やろうとしたこと
公開用ビルドとソースを確認した。`npm run build` は成功した。

## 実際に起きたこと
未収録の舵角・IMU・セッション値が0で初期化されている。前回の390px幅の画像では固定幅のカラムがはみ出していた。

## 原因
readBagの初期状態が測定値0と欠測を区別していない。CSSが固定3カラムのままである。地図の空白については仮説: canvasの固有サイズとflexのサイズ決定が競合している。

## 試して却下した方法
なし。

## 最終的な対応
欠測をNaNにしグラフではnullへ変換する。狭い画面では縦に積む。キャンバスの領域を明示しResizeObserverで再描画する。
